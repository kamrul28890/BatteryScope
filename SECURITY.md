# Security

BatteryScope runs as the current user. It needs no administrator access, does not control charging, and sends no battery data over the network. macOS notification permission is optional.

Please avoid posting registry dumps or private readings in public issues. For a sensitive vulnerability, use GitHub's private vulnerability reporting if enabled; otherwise open a minimal issue requesting a private contact without exploit or personal details.

Development builds are locally signed. They are not Apple notarized release builds.
